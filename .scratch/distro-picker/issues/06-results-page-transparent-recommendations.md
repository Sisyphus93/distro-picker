# 06: Results page with transparent recommendations

**What to build:** A Results view that presents quiz outcomes transparently and helpfully. Users see a clear top pick, 2 close alternatives, qualitative fit indicators (Strong/Good/Partial), reasons why each fits, key tradeoffs/caveats, “what to expect” summaries, and official links. The page helps users trust the recommendation and take next steps, including retaking/adjusting answers or exploring the catalog.

**Blocked by:** 04: Shared quiz UI and newcomer flow.

**Status:** ready-for-agent

- [ ] Results page displays a clear top pick plus 2 close alternatives from the recommendation engine output.
- [ ] Each recommended distro shows a qualitative fit indicator (`Strong`, `Good`, or `Partial`) and does not show numeric percentage scores.
- [ ] Each recommendation includes clear “why this fits” reasons, key tradeoffs/caveats, and a short “what to expect” summary.
- [ ] Extreme mismatches or caveat-heavy recommendations surface clear warnings/caveats where relevant.
- [ ] Recommended distros include official website/download/docs links to trusted sources.
- [ ] User can retake the quiz or adjust answers from the results experience.
- [ ] User can navigate from results to distro detail pages and/or the catalog for further exploration.
- [ ] Results layout is responsive, readable, and accessible on mobile and desktop.
