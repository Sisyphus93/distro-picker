# 05: Experienced quiz flow

**What to build:** The experienced-user quiz flow, tailored with direct technical preference questions while reusing the shared quiz UI and recommendation engine. Experienced users can complete a 6–8 question flow that maps to the same shared 10-dimension model and produces the same transparent recommendation result format.

**Blocked by:** 04: Shared quiz UI and newcomer flow.

**Status:** ready-for-agent

- [ ] Experienced quiz flow includes 7 direct technical questions covering: primary workload/use case, release model preference, package/software ecosystem priorities, hardware/GPU needs, customization vs curated defaults, stability/tinkering tolerance and maintenance style, and desktop/workflow preference.
- [ ] Experienced questions map to the same shared 10-dimension model used by the newcomer flow and recommendation engine.
- [ ] Experienced flow reuses the shared quiz UI behaviors (one at a time, progress, back, “not sure/no preference” where appropriate, accessible controls).
- [ ] Completing the experienced flow produces a recommendation result through the same engine/result shape as the newcomer flow.
- [ ] User can start the experienced flow from the Home page “I already use Linux” entry path.
- [ ] Copy/tone is technically grounded and credible without becoming niche or exclusionary.
