# 09: Distro detail page

**What to build:** A dedicated distro detail page for each curated distro, presenting the full profile standard in a clear, trustworthy layout. Users can understand what the distro is, who it’s for, where it falls short, how it rates across the shared dimensions, what day-to-day use is like, and where to find official sources.

**Blocked by:** 02: Shared domain model and curated distro dataset.

**Status:** ready-for-agent

- [ ] Each of the 16 curated distros has a reachable detail page/view powered by the shared dataset.
- [ ] Detail page shows identity and context: name, logo/visual identifier, family/base, release model, default desktop(s), and short description.
- [ ] Detail page shows “Best for”, “Not ideal for”, and key tradeoffs.
- [ ] Detail page shows ratings/rationale across the shared 10 dimensions in a clear, scannable format.
- [ ] Detail page includes “What to expect” covering install difficulty, maintenance/update style, software install experience, and who will feel at home.
- [ ] Detail page includes official website, download, and documentation links, and displays a “Last reviewed” date.
- [ ] Caveat-heavy/advanced distros display clear cautionary guidance appropriate for newcomers.
- [ ] Page is responsive, accessible, and easy to navigate back to catalog/results/home.
